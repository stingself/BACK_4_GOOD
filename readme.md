👁️ Sharingan × Rinnegan — "I'm Back"

A Flutter app featuring animated Sharingan and Rinnegan eyes with the iconic "I'M BACK" text.

Preview
🔴 Sharingan — rotating 3-tomoe eye with red glow
🟣 Rinnegan — concentric ring eye with purple glow
✨ Both eyes pulse and glow with smooth animations
💥 Gradient "I'M BACK" text that breathes
Getting Started
Prerequisites
Flutter SDK ≥ 3.0.0
Dart SDK ≥ 3.0.0
Run the app
bash
git clone https://github.com/YOUR_USERNAME/sharingan_app.git
cd sharingan_app
flutter pub get
flutter run
Project Structure
lib/
├── main.dart             # App entry point
├── home_screen.dart      # Main screen with both eyes
├── sharingan_painter.dart # Sharingan custom painter
└── rinnegan_painter.dart  # Rinnegan custom painter
Built With
Flutter (CustomPainter, AnimationController)
Zero external dependencies — pure Flutter 🎯
